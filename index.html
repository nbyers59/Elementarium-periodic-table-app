How the live PubChem version works

This HTML app first loads a compact periodic-table dataset. When you tap an element, it requests a deeper PubChem Element record for that single element and extracts readable scientific facts, where available. This is much friendlier to mobile data and faster than attempting to load full records for every element at the beginning.

  • The periodic layout and basic element identities remain available even if live data cannot load.
  • Not all fields are measured or known for synthetic, short-lived, or superheavy elements.
  • Values can differ between sources based on isotope, allotrope, pressure, temperature, and the definition of a property.
  • The “glass cube” is a stylized HTML/CSS visual, not a photograph or a true crystal structure model.

Data source: PubChem, National Library of Medicine / NIH. Use the “Open on PubChem” button for the source page and citations for a selected element.
